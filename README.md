# 🎂 Happy Birthday Cake Animation

A visually appealing Happy Birthday webpage animation created using HTML and CSS.  
This project displays an animated birthday cake with a candle flame effect and a birthday message.

The animation creates a celebratory feel and can be used as a greeting page, digital birthday card, or a creative front-end practice project.

------------------------------------------------------------

## ✨ Project Overview

This project focuses on creative UI design and CSS animations.

The webpage shows:

• An animated birthday cake built using SVG  
• A candle that appears on the cake  
• A glowing flame animation using CSS keyframes  
• A birthday greeting message

The goal of the project was to practice SVG animations, CSS keyframes, and front-end layout design.

------------------------------------------------------------

## 🛠️ Technologies Used

HTML5  
CSS3

CSS Keyframes  

This project was built using pure front-end technologies without any external libraries or frameworks.

## 🚀 How It Works

1. The cake illustration is created using SVG inside the HTML file.

2. CSS animations control:
   - Cake movement
   - Candle appearance
   - Flame flickering effect

3. Keyframe animations simulate the natural flickering of a candle flame.
